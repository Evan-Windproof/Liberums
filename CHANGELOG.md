# Changelog

## v1.0.0 — Educational Release (2026-11-17)

- Finish the teaching baseline with bilingual README, eight architecture chapters,
  ten independent LibOS lessons, learning/debugging/maintenance guides.
- Export the canonical Kernel ABI 1.2 SDK with provenance and hashes.
- Add standalone minimal, bitmap-policy and VGA/PS2 console examples, an empty-directory
  project generator, outside-consumer and mixed-LibOS QEMU/GDB validation.
- Keep the existing kernel architecture, ABI, historical tests and Phase 1–9 evidence.
- Prepare fixed-revision source/SDK/examples and validation/checksum release artifacts.
  Publication status is reported separately from preparation and tagging.

## Phase 1–9 research history

See the [historical index](docs/history.md) for unchanged original reports and evidence.
Phase 8 introduced bounded dynamic domains; Phase 9 stabilized identity/revocation/ABI
validation and repaired the keyboard RELEASE output contract. These are phase milestones,
not retroactively invented semantic-version releases.
